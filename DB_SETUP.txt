# PostgreSQL Database Configuration

## Setup PostgreSQL

### Windows (using WSL or Docker)
```
docker run --name hand-hygiene-db -e POSTGRES_PASSWORD=password -e POSTGRES_DB=hand_hygiene -p 5432:5432 -d postgres:15
```

### Connection String
```
postgresql://postgres:password@localhost:5432/hand_hygiene
```

## Environment Variables (.env)

```
DATABASE_URL=postgresql://postgres:password@localhost:5432/hand_hygiene
FLASK_ENV=development
SECRET_KEY=your-secret-key-here
```

## Database Tables Created Automatically

1. **hygiene_events** - All hand hygiene events
2. **daily_stats** - Daily aggregated statistics
3. **users** - Healthcare worker profiles

## API Documentation

### Health Check
```
GET /api/health
```

### Log Event
```
POST /api/log
Body: {
    "user_id": "USER123",
    "duration": 22.5,
    "status": "completed",
    "location": "ICU",
    "department": "Critical Care"
}
```

### Get Events
```
GET /api/logs?user_id=USER123&status=completed&days=7&limit=100
```

### Get Statistics
```
GET /api/stats?days=7&user_id=USER123
GET /api/stats/daily?days=30
GET /api/stats/user/USER123?days=30
```

### User Management
```
POST /api/users
GET /api/users/<user_id>
```
